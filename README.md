# 投資理念核心與 AI 交易探員邏輯庫 (Final Version)

## 1. 核心投資哲學與資產配置
- **總體策略**：由上而下（Top-Down）的邏輯閉環，從美林時鐘與景氣循環判斷市場位階，結合技術與籌碼鎖定買點，堅守「左側交易」逢低佈局的紀律。
- **歷史與宏觀視角**：第四次工業革命（AI）的實質生產力轉換是當前貨幣體系續命的關鍵。投資標的須具備實質技術支撐（如 2nm 先進製程）與算力成本優勢。

- **攻擊型配置 (約 15-20%)**：

## 2. 市場狀態機 (Regime Detector)
AI 探員需依據全球宏觀與 VIX 指標，將市場動態劃分為四大狀態，並切換對應的策略權重：

1. **PANIC_CRISIS (恐慌崩盤 - 左側主場)**
   - **觸發條件**：VIX >= 35，或黃金月變動 > 8.0% (黑天鵝警告)。
   - **決策權重**：情緒 (Sentiment) 40% + 技術 (Tech) 30% + 基本面 (Fund) 30%。
   - **操作方針**：極佳的左側買點。執行雷劈承接策略，尋找 MACD 底背離與恐慌極致。
2. **BEAR_TREND (空頭趨勢)**
   - **觸發條件**：宏觀資金分數 < -10 且 VIX >= 25。
   - **決策權重**：基本面 30% + 籌碼 30% + 技術 20% + 情緒 20%。
   - **操作方針**：分批試單，等待落底訊號。
3. **BULL_TREND (多頭趨勢)**
   - **觸發條件**：宏觀資金分數 > 0 且 VIX < 20。
   - **決策權重**：籌碼 (Flow) 40% + 技術 (Tech) 40% + 基本面 (Fund) 20%。
   - **操作方針**：右側順勢動能策略，持股續抱或逢回加碼。
4. **NEUTRAL_CHOPPY (震盪整理)**
   - **觸發條件**：不符合上述條件之常態市場。
   - **操作方針**：區間均衡策略，低買高賣。

## 3. 四大因子評分系統 (量化決策樹)

### A. 全球與本地情緒 (Sentiment)
- **CNN 恐懼貪婪指數**：<= 25 為極度恐慌 (尋求買進)；>= 75 為極度貪婪 (警戒過熱)。
- **VIX 動能 (ROC)**：VIX 絕對值到達 35 視為極度恐慌買點。若 5 日變化率 (ROC) > 10% 則給予情緒加分，反映短期急速崩跌的左側機會。
- **散戶多空比 (小台/微台)**：淨留倉比例 >= 10% 為「散戶過度看多 (市場擁擠，醞釀回測)」；<= -10% 為「散戶極度看空 (醞釀左側買點)」。

### B. 資金與籌碼 (Flow)
- **美股 NAAIM 經理人持倉**：
  - 極度恐慌 (+15分)：NAAIM < 40 且 S&P 500 走跌。
  - 高檔背離 (-15分)：S&P 500 創新高，但 NAAIM 下降且 < 80。
  - 極度擁擠 (-5分)：NAAIM >= 90 且 S&P 500 RSI >= 70。
- **宏觀資金流動**：DXY (美元指數) 轉強大於月線且 US10Y 殖利率 > 4.2% 時，視為流動性收縮警訊。台幣匯率貶破 32.5 為外資匯出壓力。外資期貨空單 > 4 萬口須極度警戒。

### C. 基本面與價值護城河 (Fundamental)
- **動態防線 (斐波那契)**：以 52 週高低點計算。一般模式回撤 50% 啟動安全邊際，危機模式需回撤 61.8% 始得計算支撐補償分數。
- **自動產業估值模型**：
  - **科技股 (Tech)**：P/E <= 15 為極度便宜 (+15分)；15-22 為價值便宜 (+10分)；> 30 需警戒。
  - **金融股 (Financial)**：以 P/B 估值。P/B < 1.0 為絕佳左側買點 (+15分)；> 1.5 估值高估。
  - **景氣循環股 (Cyclical)**：P/E >= 50 或 EPS <= 0 時，為景氣谷底轉折買點 (+15分)；P/E < 10 時為景氣見頂賣點 (+0分)。
- **半導體微觀數據**：庫存天數 (DOI) 達高點後緩步下滑為股價觸底領先指標；產能利用率回升至 90% 以上代表進入復甦週期。

### D. 技術面錯殺 (Technical)
- **年線乖離率 (240MA)**：乖離率 <= -20% 時，觸發極端錯殺，強制給予技術面滿分 (100分)。
- **MACD 爆量背離**：尋找 DIF 向上突破的黃金交叉、柱狀圖綠轉紅。若 US 500 成交量 > 30日均量 1.5 倍且收黑，視為恐慌拋售極致 (+20分)。
- **RSI 鈍化過濾**：RSI < 30 為超賣；但若連續超過 4 天 < 30，視為強勢空頭【鈍化區】，此時應沒收 RSI 動態加分，改看 MACD 動能。
